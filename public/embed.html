把今天的日签，放进你的网站。

选一款风格，复制 iframe。无需下载项目，也不需要安装插件。

设置与代码

参数说明

theme=dungeon
选择主题；不传或无法识别时使用暗黑地牢。经典版使用 theme=classic。
embed=1
卡片适应 iframe 宽度，减少外围空白，底部仅保留娱乐提示。
transparent=1
仅内嵌模式生效，让外围背景透明，不改变卡片配色。

建议宽度至少 280px。示例最大宽度 380px、高度 820px；高度由宿主网站控制，文案变长时可在框内滚动。需要更完整的展示，可增大 height。

请在支持 iframe 的网页或自定义 HTML 区域粘贴。普通 GitHub README 无法直接运行这个内嵌工具。若网站设置了内容安全策略，需允许日签域名；若使用 sandbox，至少允许 scripts 和 same-origin。
