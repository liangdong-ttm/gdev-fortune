把今天的日签，放进你的网站。

选一款风格和深浅配色，复制 iframe。无需下载项目，也不需要安装插件。

设置与代码

参数说明

theme=dungeon
选择主题；不传或无法识别时使用暗黑地牢。经典版使用 theme=classic。
embed=1
卡片适应 iframe 宽度，减少外围空白，底部仅保留娱乐提示。
transparent=1
仅内嵌模式生效，让外围背景透明，不改变卡片配色。
mode=dark / mode=light
控制台、暗黑地牢支持；dark 为深色，light 为浅色，不传或值无效时默认深色。其他风格忽略此参数，保持原有配色。不自动跟随系统。

跟随你的网站切换深浅色

将以下代码接入网站已有的主题切换逻辑：fortuneFrame 是日签 iframe 元素，isDark 是网站当前是否使用深色的布尔值。更新地址会重新加载日签，但不会改变当天内容。

const url = new URL(fortuneFrame.src);
url.searchParams.set('mode', isDark ? 'dark' : 'light');
fortuneFrame.src = url.href;

浅色地牢：?embed=1&theme=dungeon&mode=light
浅色控制台：?embed=1&theme=console&mode=light
深色版本将 light 改为 dark 即可。外围透明与深浅配色可同时使用。

建议宽度至少 280px。示例最大宽度 380px、高度 820px；高度由宿主网站控制，文案变长时可在框内滚动。需要更完整的展示，可增大 height。

请在支持 iframe 的网页或自定义 HTML 区域粘贴。普通 GitHub README 无法直接运行这个内嵌工具。若网站设置了内容安全策略，需允许日签域名；若使用 sandbox，至少允许 scripts 和 same-origin。
